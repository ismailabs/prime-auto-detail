# Prime Auto Detailing — Portfolio Website

A fictional premium automotive detailing portfolio project for Kuala Lumpur and Selangor, Malaysia.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion for React
- React Router

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Notes

- Prime Auto Detailing is fictional. All prices, testimonials, contact details and business information are illustrative.
- The quote form validates and simulates submission in the browser; it does not send or store data.
- The WhatsApp number is intentionally fictional.
- Remote automotive photography is loaded from Unsplash image URLs and is presented as stock imagery.
- `public/built-by-ismail.png` is the supplied footer banner.
